# PART 1 — GLOBAL RULES FOR ALL CHANNELS

These requirements apply to all gaming review channels unless an explicitly approved channel-specific rule overrides them.

## 1. Language

- All scripts must be written in English.
- Use natural, fluent English.
- Scripts must be suitable for professional AI narration.
- Avoid unnecessary complicated phrasing.
- Avoid repetitive AI-generated language.
- Do not switch languages.
- Do not include Serbian explanations in scripts.

## 2. Script output

The final voiceover script must contain only text intended for narration.

Never include:

- URLs
- Source citations
- Markdown links
- Research references
- Instructions for the AI
- Notes for the video editor
- Unnecessary timestamps
- Technical generation metadata
- Unrequested introductions or explanations

If a channel's approved reference scripts contain section headings, preserve them in the saved script according to that channel's rules.

Provide a separate clean narration version for ElevenLabs, excluding non-spoken headings and metadata.

## 3. Writing style preservation

Every channel must have its own writing identity.

Preserve:

- Opening style
- Introduction wording when fixed
- Paragraph organization
- Section sequence
- Sentence length patterns
- Narration perspective
- Transition style
- Level of detail
- Critical or positive tone
- Conclusion structure
- Call-to-action wording when approved
- Script length
- Character-count restrictions

Do not introduce stylistic variations unless permitted by the channel profile.

The game-specific information changes, but the established channel format remains consistent.

## 4. Accuracy

Never invent:

- Personal gameplay experiences
- Game features
- Combat systems
- Performance benchmarks
- Release information
- Developer information
- Multiplayer capabilities
- Platform availability
- Specific testing results

Use verified research information.

If firsthand gameplay or testing is required, allow me to supply notes.

Do not claim that the reviewer personally played or tested a game unless that experience has been provided.

For unreleased games, distinguish confirmed gameplay information from expectations.

## 5. Script length

The default production target for channels without verified length rules is 4,000–5,000 characters.

This is a provisional production target, not a claim that every existing channel previously used the same length.

Channel-specific verified limits take precedence.

Character counts must be measured programmatically.

Use actual characters, including spaces and punctuation, rather than estimating length from tokens.

## 6. Originality

Every channel must retain its own established format.

Do not copy a script from one channel and merely replace the channel name.

If the same game is assigned to multiple channels:

- Research may be reused.
- Factual information may be shared.
- Narration must be generated independently.
- Channel-specific structures must remain intact.
- Writing must not become a superficial paraphrase of another channel's script.

## 7. Abbreviations and narration

Use speech-friendly formatting.

For technical scripts, use established lowercase styling for abbreviations such as usb-c, qmk, via, and ghz where appropriate.

Provide pronunciation overrides for game titles, brands, abbreviations, and product names.

Do not modify official product names or titles in saved metadata.
